# Component id -> name map

Extracted statically from the game's Generated.Code.dll (443 components).
Every metaclass implements IComponentMetaclass and is tagged [ComponentId(N)].

Do NOT obtain this by reading ComponentDatabase.MetaclassMap from a running
server. That type discovers components by scanning AppDomain assemblies in a
private constructor that runs exactly once; touching it before the game has
loaded Generated.Code leaves the map permanently empty, which breaks component
initialisation for the whole process.

Regenerate with:
    ilspycmd -o out -p UnityClient@Windows_Data/Managed/Generated.Code.dll
then grep 'public class X : IComponentMetaclass' + '[ComponentId(Nu)]'.
