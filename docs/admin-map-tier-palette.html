Admin world map — tier palette review

Every figure below is computed, not judged by eye: WCAG 2.x relative luminance and contrast ratio, CIEDE2000 colour difference, and Machado 2009 colour-vision-deficiency simulation at severity 1.0. “On screen” means the colour after the map's layer opacity is composited over the ocean #09151d — the old palette was drawn at opacity:.38, so its CSS hex was never what an operator actually saw.
