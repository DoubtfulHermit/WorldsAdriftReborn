    One-island visual acceptance run

    Haven → Mental Facility → Haven using the existing guarded travel operations. The console reports lifecycle state only; whether the terrain LOOKS right is a human judgement and is never asserted here.

    1. Select the connected player in Operations, and confirm they are grounded on Haven below.
    2. Travel to Mental Facility. Watch this player's row go REQUESTING → WAITING ACK → READY.
    3. In game, look at the island: terrain mesh, collision underfoot, and its resources appearing only after the ground does.
    4. Return to Haven, then watch the row go DRAINING → UNLOADING → ABSENT. A RETAINED (LEGACY) row means this client cannot receive a terrain removal and will keep it for the session.
    5. Record what you saw. Nothing on this page is evidence that the visuals were correct.

    Both steps dispatch the same allowlisted, CSRF-bound travel commands as the Operations panel.
